# HVAC Chapter 5 Escape Room

Interactive classroom review game for **Chapter 5: Components, Symbols, and Circuitry of Air-Conditioning Wiring Diagrams**.

## Student Game
The game is in `index.html` and includes:
- 5 themed rooms
- 25 total questions
- Short-answer first attempt
- Automatic multiple-choice conversion after an incorrect first attempt
- Visual clue backgrounds for every room
- Room code collection and a final escape code
- First-try score and timer

## Teacher Materials
See `TEACHER_GUIDE.txt` for the room topics, classroom directions, answer key, and final escape code.

## Publish with GitHub Pages
In this repository, go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. Once GitHub finishes publishing, the student game should be available at:

https://ceourbanrootzsociety.github.io/HVAC-Chapter-5-Escape-Room/
